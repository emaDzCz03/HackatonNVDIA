# Casos de prueba mínimos

1. Entrega habitual.
2. Foto borrosa u oscura.
3. Producto desconocido.
4. Falta el costo de compra.
5. Servidor de IA no disponible.
6. Costo mayor al precio, con margen negativo.

Cada caso debe registrar entrada, resultado esperado, resultado obtenido y
comportamiento de recuperación.
